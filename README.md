# 餐饮点单系统

本项目用于本地部署、二次开发与业务定制，包含服务端与微信小程序打包产物。

## 项目说明

- 当前仓库默认按本地调试与二开维护场景整理。
- 远程插件市场、在线升级、原官方外链能力已收口或计划逐步收口。
- 小程序端如需正式发布，请替换为你自己的 `appid`、服务端域名与业务名称。

## 目录结构

- `TP8服务端`：ThinkPHP 服务端项目
- `微信小程序`：微信小程序打包产物与工程配置
- `addons`：兼容模板与公共插件资源

## 发布前检查

1. 修改服务端站点名称、默认小程序名称与版权文案。
2. 检查微信小程序工程名与 `appid` 是否为你的项目配置。
3. 将小程序与服务端请求域名替换为你自己的正式域名。
4. 确认数据库、支付、地图、短信、存储等参数均为你自己的账号配置。
